#### 1. 画面サイズ・レイアウト（最重要）

* **レスポンシブ前提:** スマホ（縦画面）で快適に遊べることを最優先にしてください。
* **推奨コンテナサイズ:** **`360px × 480px` (比率 3:4 程度)**
* 親枠側で `max-w-sm`（横幅約384px）のコンテナに収めます。
* 画面いっぱいに広げる設計ではなく、指定された枠（Div）の内部で完結するように作ってください。

---

#### 2. 操作方法（スマホ ＆ PC 両対応）

* **タッチ操作のみ:**
* スマホで遊ぶため、画面上のタップ・スワイプ・仮想ボタン（クリック・ドラッグ）で全操作が完結するようにしてください。
* キーボード操作は不可です

---

#### 3. ゲームのフロー（ステート管理）

ゲームは必ず以下の**3つの状態**を行き来できるように設計してください。

```text
 [ START画面 ] ──(タップ)──> [ PLAY画面 ] ──(ゲームオーバー)──> [ RESULT画面 ]
       ▲                                                            │
       └────────────(リトライ)──────────────────┘

```

* **START:** タイトル、簡単なルール説明、「スタート」ボタン
* **PLAY:** プレイ中（タイマーカウントダウン、スコア加算）
* **RESULT:** 最終スコア、「もう一度遊ぶ」ボタン

---

#### 4. アセット（画像・音・フォント）の制限

* **画像:**
* **外部画像URL（`https://...`）の使用は禁止**（リンク切れ防止のため）。
* 絵文字（🍎, 👾, 💣, 🚀 など）や、Tailwindのアイコン（Lucide Iconsなど）、または inline SVG を使って表現してください。


* **音・BGM:**
* **使用禁止**（自動再生ブロックによるエラーや、WebAudio APIの複雑化を防ぐため）。


* **フォント:**
* ブラウザ標準フォント（`font-sans`, `font-mono`）のみを使用してください。



---

#### 5. 技術仕様・コードルール

**【TypeScript / React で書く場合】**

1. **1ファイル完結（推奨）:**
* 提出の手間を減らすため、可能な限り `index.tsx` 1ファイル（または同階層の2〜3ファイル）にまとめてください。


2. **外部ライブラリ禁止:**
* `canvas-confetti` や `framer-motion` などの追加 `npm` パッケージは使わず、React標準（`useState`, `useEffect`, `useRef`）と Tailwind CSS だけで実装してください。


3. **アニメーション:**
* Tailwindのクラス（`animate-bounce`, `transition-all`, `duration-300` など）や `requestAnimationFrame` を活用してください。
